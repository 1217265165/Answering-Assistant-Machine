# 🚀 跨页多模态极速答题辅助机 (支持 DeepSeek/豆包/Gemini/GPT)

> **💡 核心定位：**
> 这不是一个“闭着眼睛挂机”的外挂，而是一个**为你砍掉 99% 繁琐机械操作的“智能副驾”**。
> 脚本**不会**替你勾选 A/B/C/D，也**不会**替你点击下一题。这是为了让你拥有最终的答案审核权（防止 AI 幻觉出错），同时利用真实的鼠标点击间隔，完美规避学校教务系统的“防刷课/防作弊”风控。
> **它的魔法在于：**将原本极其痛苦的“框选截图 → 复制 → 切换网页 → 粘贴 → 打字提问”压缩成了**后台瞬间秒传**。你只需负责：**看 AI 答案 → 勾选网页选项 → 点下一题**。

## ✨ 核心功能亮点

* **🤖 多 AI 平台秒切**：完美兼容 DeepSeek、字节豆包 (Doubao)、Google Gemini 和 ChatGPT。面板一键切换，跨网页瞬间发包。
* **🎯 独创“视觉选框绑定”**：无需手写任何复杂的 CSS 代码。用鼠标在网页上点一下题目区域，脚本会自动解析并永久记住这个抓取范围。
* **⏭️ “下一题”无缝流转**：当你做完当前题目，点击教务系统自带的“下一题”时，脚本会自动捕获新题目，并在后台默默传给 AI，实现行云流水的答题节奏。
* **📝 自定义专属提示词**：面板自带提示词修改框。你可以随时根据不同的学科，给 AI 设定不同的“人设”和格式要求（内置防冗余机制，长提示词仅首题发送，省流高效）。
* **⚡ 极速 OCR 纯文本传输**：内置 OCR 接口，将图片瞬间转化为纯文本传给 AI，响应速度远超直接发送庞大的图片。

## 🛠️ 安装指南

### 1. 安装 Tampermonkey 扩展

请先在你的浏览器（Chrome / Edge 等）中安装 [Tampermonkey (油猴) 扩展](https://www.tampermonkey.net/)。

### 2. 导入脚本代码

1. 点击浏览器右上角的油猴图标，选择 **“添加新脚本”**。
2. 将编辑器里默认的内容全部清空。
3. 复制本项目中的脚本源码，粘贴到油猴编辑器中。
4. 按下 `Ctrl + S`（Mac 为 `Cmd + S`）保存脚本，并确保脚本处于 **“已启用”** 状态。

*(注：脚本默认匹配了 `*.upc.edu.cn` 系列网址。如果你要在其他平台的网课使用，请在代码头部的 `// @match` 列表中添加你的网课网址)*。

## 📖 新手使用教程

### 第一步：双开网页布局

为了让脚本正常工作，请在浏览器中同时打开两个标签页（建议左右分屏）：

1. **你的网课/考试页面**。
2. **你的目标 AI 页面**（例如打开 `chat.deepseek.com` 或豆包网页版，并保持登录状态）。

### 第二步：首次“视觉绑定”（极其重要！）

刷新你的网课页面，右下角会弹出一个控制面板。在开始全自动流转前，我们需要告诉脚本“题目到底在哪里”：

1. 点击面板上的 **`🎯 选框绑定`** 按钮。
2. 你的鼠标会变成十字准星。将鼠标移动到网页的题目上，你会看到题目周围出现了一个 **红色的高亮方框**。
3. 移动鼠标，确保红框完整包裹了“当前题目 + 所有选项”，然后 **点击鼠标左键**。
4. 面板上方状态变为绿色提示 **“🔴 自动抓取：已绑定”**。脚本已成功记住该区域！

### 第三步：开启极速答题流

绑定成功后，你就可以体验丝滑的答题流了：

1. **当前题目**：点击面板上的 **`🚀 方式0：执行自动抓取`**，题目会瞬间发给 AI。
2. **看答案与作答**：瞄一眼面板上的预览框或旁边的 AI 窗口，在网课页面手动勾选正确的 A/B/C/D。
3. **丝滑流转**：点击网课系统自带的 **“下一题”**。
4. **见证魔法**：脚本检测到你切换了题目，会**自动**在后台截取新题目并传给 AI。你不需要再点任何控制面板的按钮，只需重复“看答案 → 勾选 → 下一题”即可！

## 💡 备用功能与常见问题 (FAQ)

**Q：遇到某道题排版特别奇怪，或者绑定区域抓取不全怎么办？**

> 你可以使用面板最下方的 **`🟡 方式1：单次鼠标选取`**。点击它后，单独框选这道特殊的题目发送。发送完它会自动恢复正常，不影响你下一题的继续流转。

**Q：为什么我改了提示词，但发送给 AI 时它还是只发了题目？**

> 为了防止长篇提示词占用过多的 AI 上下文，你设置的“提示词”只会随着**每轮对话的第一道题**一起发送。如果你中途修改了提示词，请在 AI 的网页按 `F5` 刷新一下，或者新建一个 AI 会话，脚本就会重新发送新的提示词了。

**Q：提示“无法生成唯一路径，请换一个更外层的红框”怎么办？**

> 这说明你点击的元素没有明显的特征（比如网页代码里没写 Class 或 ID）。请在点击绑定时，把鼠标稍微往外围移动一点，框选一个更大的外层容器框再点击即可。
