
# 🚀 跨页多模态极速答题辅助机 (v1.0 万能双绑版支持 DeepSeek/豆包/Gemini/GPT,无需API)

> **💡 核心定位：你的智能答题副驾**
> 这不是一个“闭着眼睛挂机”的危险外挂，而是一个为你砍掉 99% 繁琐机械操作的“极速智能副驾”。
> 脚本**不会**替你盲目勾选答案。由 AI 提供参考，由你做最终裁决并点击翻页。这不仅能防止 AI 幻觉带来的错题，更利用了真实的鼠标点击节奏，完美规避学校教务系统的“防刷课/防作弊”风控。
> **它的魔法在于：**将极其痛苦的“截图 → 切换网页 → 粘贴 → 打字提问”压缩成了**后台瞬间秒传**。你只需负责：**看 AI 答案 → 勾选网页选项 → 点下一题**。

## ✨ 核心功能亮点

* **🆓 完全免费，无需 API**：直接对接网页版 AI 大模型，不用折腾配置复杂的 API Key，开箱即用，零成本白嫖最强算力。
* **🎯 独创“双重视觉绑定” (核心突破)**：全网首创！无论网课系统的界面多奇葩，只需用鼠标点一下“题目区域”，再点一下“下一题按钮”，脚本就能永久记住它们，实现无视 DOM 变化的降维打击适配。
* **🤖 多 AI 平台秒切**：完美兼容 DeepSeek、字节豆包 (Doubao)、Google Gemini 和 ChatGPT。面板一键切换，跨网页瞬间发包。
* **⏭️ 丝滑全自动流转**：当你做完当前题目，点击绑定的“下一题”时，脚本会自动捕获新题目，并在后台默默传给 AI，节奏行云流水。
* **📝 界面自定义提示词**：面板自带提示词修改框，即改即用。针对不同学科设定不同的 AI 人设（内置防冗余机制，长篇要求仅首题发送，省流高效）。
* **⚡ 极速 OCR 纯文本传输**：内置 OCR 接口，将图片瞬间转化为纯文本传给 AI，响应极速，告别上传图片的卡顿。

## 🛠️ 安装指南

### 1. 安装 Tampermonkey 扩展

请先在你的浏览器（Chrome / Edge 等）中安装 [Tampermonkey (油猴) 扩展](https://www.tampermonkey.net/)。

### 2. 导入脚本代码

1. 点击浏览器右上角的油猴图标，选择 **“添加新脚本”**。
2. 将编辑器里默认的内容全部清空。
3. 复制本项目中的脚本源码，粘贴到油猴编辑器中。
4. 按下 `Ctrl + S`（Mac 为 `Cmd + S`）保存脚本，并确保脚本处于 **“已启用”** 状态。

*(注：脚本默认支持所有 `*://*/*` 网址，进入任何考试页面右下角均会唤出面板。)*

## 📖 新手丝滑起飞教程

### 第一步：双开网页布局

请在浏览器中同时打开两个标签页（建议左右分屏）：

1. **你的网课/考试页面**。
2. **你的目标 AI 页面**（例如打开 `chat.deepseek.com` 或豆包网页版，并保持登录状态）。

### 第二步：双重绑定（仅首次使用需配置，极其重要！）

刷新你的网课页面，右下角会弹出一个控制面板。在开始前，我们需要告诉脚本“题目在哪”和“翻页键在哪”：

1. **绑题目**：点击面板上的 **`🎯 绑题目框`** 按钮。鼠标变成十字准星后，悬停在网页的题目上（会出现**红色高亮框**）。确保红框完整包裹了“题目 + 所有选项”，**点击左键**完成绑定。
2. **绑翻页**：点击面板上的 **`⏭️ 绑翻页键`** 按钮。悬停在网页的“下一题 / Next”按钮上（会出现**黄色高亮框**），**点击左键**完成绑定。
3. 面板上方状态变为绿色提示 **“🟢 题目与翻页均已绑定”**。配置完成！

### 第三步：开启极速答题流

绑定成功后，就可以体验丝滑的流水线了：

1. **首题发送**：点击面板上的 **`🚀 方式0：执行自动抓取`**，第一道题会瞬间发给 AI。
2. **看答案与作答**：瞄一眼面板上的预览黑框或旁边的 AI 窗口，在网课页面手动勾选正确的 A/B/C/D。
3. **丝滑流转**：点击网课系统上的 **“下一题”**（就是你刚才绑定的那个按钮）。
4. **见证魔法**：脚本检测到翻页动作，会**自动**在后台截取新题目并传给 AI。你无需再点面板上的任何按钮，只需重复“看答案 → 勾选 → 下一题”即可！

## 💡 备用功能与常见问题 (FAQ)

**Q：遇到某道题排版特别奇怪，或者图片巨大抓不全怎么办？**

> 请使用面板最下方的 **`🟡 方式1：单次鼠标选取`**。点击它后，手动单独框选这道特殊的题目。发送完它会自动恢复，不影响你后续题目的自动流转。

**Q：为什么我改了提示词，但发送给 AI 时它还是只发了短题目？**

> 为了防止长篇提示词占用过多的 AI 上下文，你设置的“长提示词”只会随着**每轮对话的第一道题**一起发送。如果你中途修改了要求，请在 AI 的网页按 `F5` 刷新一下，或者新建一个 AI 会话，脚本就会重新带上前置提示词了。

**Q：提示“无法生成唯一路径，请换一个更外层的红框”怎么办？**

> 这说明你点击的元素代码没有明显的特征定位。请在点击绑定时，把鼠标稍微往外围移动一点，框选一个更大的外层容器框再点击即可。
